📖 Guide de démarrage (10 minutes, 100 % gratuit, fichiers privés)

1. Projet Supabase

  1. Créez un compte gratuit sur supabase.com puis un nouveau projet (région Europe).
  2. Dans Storage → New bucket, créez un bucket nommé saves. ⚠️ Laissez-le privé (ne cochez PAS « Public bucket »).
  3. Dans Authentication → Providers, vérifiez que Email est activé.
  4. Dans Authentication → Users → Add user, créez votre compte (e-mail + mot de passe). Activez « Auto confirm user » ou confirmez l'e-mail reçu.

2. Politiques d'accès (RLS)

Dans Storage → Policies → New policy ou via SQL Editor, exécutez ceci en remplaçant l'e-mail par le vôtre (il limite l'accès à votre seul compte) :

create policy "owner select" on storage.objects
  for select to authenticated
  using (bucket_id = 'saves' and auth.jwt() ->> 'email' = 'vous@exemple.com');

create policy "owner insert" on storage.objects
  for insert to authenticated
  with check (bucket_id = 'saves' and auth.jwt() ->> 'email' = 'vous@exemple.com');

create policy "owner update" on storage.objects
  for update to authenticated
  using (bucket_id = 'saves' and auth.jwt() ->> 'email' = 'vous@exemple.com');

create policy "owner delete" on storage.objects
  for delete to authenticated
  using (bucket_id = 'saves' and auth.jwt() ->> 'email' = 'vous@exemple.com');

3. Configurer l'appli

  1. Dans Settings → API, copiez l'URL du projet et la clé anon public.
  2. Cliquez sur ⚙️ Réglages, collez ces deux valeurs, puis « Enregistrer ».
  3. Connectez-vous avec l'e-mail et le mot de passe créés à l'étape 1.4.

4. Héberger la page

  1. Créez un compte GitHub, un dépôt public, activez Settings → Pages → Deploy from branch.
  2. Déposez ce fichier HTML sous le nom index.html à la racine du dépôt : la page sera servie sur https://votre-nom.github.io/depot/.
  3. Alternative sans hébergement : gardez le fichier sur une clé USB, il fonctionne à l'identique en local (double-clic).

🔒 La page publiée est publique, mais elle ne contient aucune donnée : sans votre mot de passe, elle n'affiche rien. Le jeton de session reste en mémoire dans l'onglet et disparaît à la fermeture — pensez à vous déconnecter avant de quitter le PC de la médiathèque.
