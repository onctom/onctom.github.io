📖 Guide de démarrage (5 minutes, 100 % gratuit)
  1. Créez un compte gratuit sur supabase.com puis un nouveau projet (région Europe).
  2. Dans Storage → New bucket, créez un bucket nommé saves et activez l'option Public bucket.
  3. Dans Settings → API, copiez l'URL du projet et la clé anon public.
  4. Ouvrez SaveVault, cliquez sur ⚙️ Réglages, collez ces deux valeurs, puis « Enregistrer ».
  5. Pour héberger cette page : créez un compte GitHub, un dépôt public, activez Pages et déposez-y ce fichier HTML. Sinon, gardez-le sur une clé USB : il fonctionne à l'identique.

⚠️ Bucket public = quiconque connaît l'URL peut télécharger vos fichiers. Pour un usage privé, laissez le bucket privé et créez des signed URLs dans les politiques Supabase. Les identifiants anon ne permettent jamais d'effacer votre projet.
